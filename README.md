# 拾刻

把此刻轻轻拾起。

拾刻是一个温暖、轻量的本地日记 App。可以留下一句话，慢慢写完一篇日记，把照片和声音放进记录，也可以给未来的自己寄一封信。

记录保存在自己的手机上，无需注册账号。

## 下载安装

**当前公开版本：拾刻简版 1.0.12。** 手机桌面上的名称仍然是「拾刻」。

[下载安卓安装包](https://github.com/SgRpg/shike/releases/download/android-1.0.12/shike-plain-1.0.12-android.apk) · [查看发布说明](https://github.com/SgRpg/shike/releases/tag/android-1.0.12)

支持 Android 8.0 及以上的 ARM 手机，安装包同时包含 ARM64 和 ARMv7。下载 APK 后打开文件，按手机提示允许该来源安装即可。

已经安装简版时，直接覆盖安装新版，记录会保留，请不要先卸载。如果原先使用的是彩蛋版，两版的数据相互独立：先在原 App 中导出备份，再到简版中导入。

GitHub 仅发布简版安装包。简版保留日记、照片、语音、心情反馈和备份等功能，去掉了彩蛋奖励与卡包。

## 在拾刻里，可以做什么

### 此刻：随手留下一句

首页输入框会随着一天中的时间，换一句轻轻的问候。写下文字，选一个心情色点，就能把这一刻收好。心情色点从左到右对应 0–5 分；还没选心情时，圆点会依次轻轻弹起提醒。

想多写一些，可以直接点「写日记」。正文支持照片、短语音和句子引用，未完成的内容会保存为草稿，从首页「有几篇未完成」的小入口继续写。

### 拾光：回看自己的日子

记录按时间倒序排列，日期、心情色点和文字摘要放在一起。搜索可以输入关键词，也可以点日历选择一天或一段日期；长按日期可直接筛选单日。

写作时选中一句话，可以把它引用到另一篇已完成的日记。阅读时点按细虚线下划线，便能走到那篇记录，再逐级返回。

日记也可以导出为图片：先预览，确认后收进相册，方便自己留存。

### 时间胶囊：给未来写封信

写完信后选择开启日期和时间，再预览寄出。未到期的信封会留在拾光列表中，内容暂时封存；到期后就能像普通日记一样阅读。

时间胶囊支持本地到期通知。手机的通知权限和省电策略可能影响提醒时间，打开 App 后仍会按设定时间判断是否可以阅读。

### 心迹：看看情绪走过的路

趋势图支持周、月切换。同一天写了多篇日记，会用当天的平均心情作为折线图上的点；没有记录的日期不绘制数据点。

热力图把每天的心情铺在日历上，可以按心情色点筛选。点一天，就能查看那天的记录。

### 拾影：留下照片，也留下当时的一句话

从系统选择照片导入，写一段自己的描述。照片详情支持放大浏览，点小铅笔修改描述，点右上角的细线垃圾桶删除照片。

### 角落：照顾好自己的记录

- 导出、导入备份，带上日记、草稿、照片、语音、时间胶囊和引用关系。
- 两部安卓手机连接同一 Wi-Fi 后，通过配对二维码直接迁移数据。
- 查看权限与显示相关设置，阅读「关于拾刻」里的故事。

日记可以记录写作时的城市和天气。定位、天气需要相应权限与网络，获取不到时仍可继续写作；历史日记中的环境信息不会事后补写。

## 关于数据

拾刻不提供账号或云同步，日记内容保存在手机本地。天气查询需要联网，附近迁移使用同一局域网。

建议定期导出备份，并把备份放在手机之外妥善保存。卸载 App 或清除应用数据可能删除本地记录。

## 源码与版本

仓库保留完整版业务源码，便于继续开发和按 Git 历史回退；公开安装包只提供简版。私人照片素材、正式签名密钥、日记数据和本地开发缓存不进入仓库。

- [`shike_android/`](shike_android/)：完整版安卓工程，保留彩蛋、奖励规则和卡包实现。
- [`shike_android_plain/`](shike_android_plain/)：公开简版对应的安卓工程。
- [`docs/android/SOURCE-1.0.12.md`](docs/android/SOURCE-1.0.12.md)：源码快照、构建入口与签名说明。

两套工程均使用 Flutter、Dart、SQLite 与 Kotlin，安卓能力不依赖 Google 服务。推荐使用本次开发所用的 Flutter 3.47.8、JDK 17、Android SDK 36 和 Build Tools 36.0.0，并保留依赖锁定文件。

运行完整版源码：

```sh
cd shike_android
flutter pub get
flutter run -t lib/github_main.dart --dart-define=SHIKE_APP_VERSION=1.0.12
```

运行简版时，将目录换为 `shike_android_plain`，入口相同。

这份源码不包含私人照片库。缺少照片素材时，完整版会跳过对应照片奖励，不会影响写日记，也不会在后来补齐素材时追补已经跳过的机会。

1.0.12 已完成签名构建。本轮没有进行新的手机操作或功能测试；具体字体下的视觉效果、通知与双机迁移，仍需结合实际设备确认。
