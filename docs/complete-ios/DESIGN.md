# 完整版界面接入约束

完整业务通过新增 `lib/complete/` 页面接入，基于当前确认版本复制布局并修改交互；原 `lib/refined/` 页面保留。默认入口接入已经单独获得用户授权。明确的演示开关使用隔离的内存数据，不接触正式 SQLite 日记。

沿用暖白 `#FFFDFA`、深灰 `#24262C`、辅助蓝灰 `#64728A`、浅灰 `#A0A8B4`、分隔线 `#EAE8E4`、柔和卡底 `#F5F1EA`。字体、图标和页面边距继续由既有 `refined/design.dart` 定义；不重新生成主题，不改变四个主页面结构。

引用新增视觉只用于正文及选字菜单：正文颜色保持不变、细灰虚线，按下时仅下划线短暂变浅橘。选字菜单是黑色圆角，触控高度至少 44；引用选篇采用纸面底色、顶部拖动条、搜索及日期倒序列表，右侧“引用”与摘要预览分开。

引用面板约占半屏：

```text
       ──
   搜索日记
   10月28日
   日记正文摘要…             引用
   ────────────────────────
   10月27日
   另一篇的摘要…             引用
```

不增加彩色导航高亮、中心保存文案或未选心情云朵；保留从左到右的色点波浪提醒。多张彩蛋合为一个底部入口，点开才展示本次全部卡片。草稿、未到期胶囊不会出现在引用目标面板。

应用 frontend-design 与 UI/UX Pro Max 时优先遵守已确认参考图，不用技能的通用美学建议替换现有方向。
